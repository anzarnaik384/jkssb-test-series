# JKSSB Test Series

Starter Android app for a JKSSB practice/test-series app.

Included:
- Home screen
- 10 sectional test categories
- Full-length mock test
- Multiple-choice questions
- Timer
- Instant scoring
- Review of answers
- Android target SDK 36

Build:
1. Open this folder in Android Studio.
2. Let Gradle sync.
3. Build > Generate Signed Bundle / APK.
4. For Google Play, generate a signed `.aab`.

This starter contains sample questions. Replace/expand them with your licensed or self-created JKSSB question bank before publishing.
